# ESS 배터리 수명 예측

AI 데이터센터 전력 수요 증가와 재생에너지 변동성 확대로, 안정적인 전력 공급을 위한 ESS의 중요성이 커지고 있다. 
배터리 수명 예측을 통해 예기치 못한 설비 중단과 불필요한 교체 비용을 줄이고, 피크 대응과 유지보수 계획을 지원할 필요가 있다.  
본 프로젝트는 초기 100사이클 데이터로 수명 예측 모델을 검증해, 교체 계획과 충방전 운영 전략 수립에 활용할 가능성을 평가한다.

## 프로젝트 개요

- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12), 유효 수명 라벨 46셀
- 평가 데이터 : Batch 2 (2018-02-20), 원본 47셀 중 유효 수명 라벨 39셀
- 태스크 : Regression (Cycle Life 예측)

## EDA

- Cycle Life 분포
    - 분포 형태 및 장단수명 비율 요약 : 단수명은 500사이클 미만, 장수명은 1,000사이클 초과로 구분했다. Batch 1의 평균·중앙값은 844.7·858.5사이클이고 단수명 0.0%, 장수명 21.7%였다. Batch 2는 평균·중앙값 565.7·472.0사이클로 짧은 수명 쪽에 셀이 많이 모이며, 단수명 71.8%, 장수명 7.7%였다. 비율은 유효 라벨이 있는 셀을 기준으로 계산했다.
    - 핵심 발견 : Batch 2의 39셀 중 30셀(76.9%)은 Batch 1의 최소 수명인 534사이클보다 짧아, 학습과 평가 데이터의 수명 분포가 크게 다르다.

- 열화 곡선 분석
    - 장수명 vs 단수명 셀의 열화 속도 차이 : Batch 2의 전체 관측 곡선을 두 구간으로 근사했을 때, 후기 정규화 용량 기울기의 중앙값은 단수명 28셀에서 약 −0.00156/사이클, 장수명 3셀에서 약 −0.000612/사이클이었다. 단수명 그룹의 후기 용량 감소가 더 가팔랐지만, 장수명 표본이 작고 사후 분석이라는 한계가 있다.
    - Knee point 존재 여부 및 발생 시점 : 탐색한 Knee 후보는 Batch 1에서 42/46셀, Batch 2에서 43/47셀에 나타났으며 발생 시점의 중앙값은 각각 약 613·353사이클이었다. 이 집계에는 수명 라벨이 없는 셀의 관측 곡선도 포함한다.
    - 핵심 발견 : Batch 2에서는 단수명 그룹의 후기 용량 감소가 더 가파르고 배치 전체의 Knee 후보 시점도 더 빨랐다. Knee 후보는 전체 관측 곡선으로 계산한 탐색 결과이며, 100사이클 이후 정보가 포함되므로 초기 예측 모델의 입력으로 사용하지 않는다.

- ΔQ(V) 곡선 분석
    - Cycle 100 - Cycle 10 차이 곡선 형태 : `ΔQ(V) = Q100(V) − Q10(V)`를 3.5–2.0V 구간의 동일한 1,000개 전압 지점에서 계산했다. 곡선은 대체로 약 2.9–3.1V 부근에서 음의 골을 보이며 셀마다 골의 깊이와 전체 변화량이 달랐다.
    - 장단수명 셀 간 ΔQ 형태 비교 : Batch 2에서는 단수명 그룹의 평균 곡선이 장수명 그룹보다 더 깊은 음의 골을 보였다. 다만 두 그룹의 곡선이 겹치고 장수명 셀이 3개뿐이므로, 곡선 모양만으로 수명을 완전히 구분하기는 어렵다.
    - 핵심 발견 : ΔQ 로그 분산과 수명의 Pearson 상관계수는 Batch 1 −0.886, Batch 2 −0.902, Batch 3 −0.702로 모두 음수였다. 초기 수명 예측 후보로 유효하지만, 같은 회귀식이 다른 배치에서도 같은 정확도를 보장하지는 않는다.

- 충전 속도(C-rate)와 수명의 관계
    - 충전 프로토콜별 평균 수명 비교 결과 : Batch 1의 `3.6C(80%)-3.6C`는 평균 1,182.0사이클(3셀), `5.4C(80%)-5.4C`는 546.5사이클(2셀)이었다. 동일한 `4.8C(80%)-4.8C` 정책에서도 Batch 1은 753.0사이클(2셀), Batch 2는 483.6사이클(5셀)로 차이가 났다. 전체 정책별 결과는 EDA 실행 후 생성되는 `results/five_questions/policy_life_stats.csv`에서 확인할 수 있다.
    - 핵심 발견 : 충전 정책과 수명의 관계는 배치 및 다른 실험 조건의 영향을 함께 받는다. 프로토콜별 표본이 작고 관찰 데이터이므로, C-rate 하나가 수명 차이를 일으켰다고 단정할 수 없다.

- 추가 확인한 내용
    - Batch 3의 유효 라벨은 44/46셀이고 평균·중앙값 수명은 1,059.7·1,005.5사이클이었다. Batch 3은 배치 비교 EDA에 사용했다.
    - Batch 2의 8셀, Batch 3의 2셀은 수명 라벨이 누락되어 수명 관련 통계에서 제외했다. 정답 수명을 임의로 보간하지 않았다.
    - 일부 Batch 1 셀은 종료 시점에도 용량이 높게 남아 있어, 실험 종료와 실제 EOL을 구분하는 라벨 검증이 필요하다. 원본 온도·내부저항에도 비현실적인 값이나 0값이 있어 해당 피처를 추가하기 전에 정제 기준을 마련해야 한다.

## Modeling

### 피처 엔지니어링 전략

EDA에서 세 배치 모두 수명과 음의 상관관계를 보인 `log10_delta_q_var`를 초기 방전곡선 변화의 대표 피처로 선택했다. 이는 Cycle 100과 Cycle 10의 ΔQ 분산(`ddof=0`)에 상용로그를 적용한 값이다. 여기에 충전 정책 정보를 추가하기 위해 정책 문자열에서 추출한 `SOC_switch_pct`를 두 번째 피처로 사용했다. C1=C2인 정책에서는 실제 전류 전환이 없으므로 이 값은 정책의 SOC 값으로 해석한다.

EDA 노트북을 실행해 생성한 `cell_metadata.csv`, `delta_q_features.csv`, `current_features.csv`를 `cell_uid`로 일대일 결합한다. 수명이 누락되거나 0 이하인 셀, ΔQ 계산이 유효하지 않은 셀은 제외한다. 피처 결측치의 중앙값 대체와 표준화는 각 학습 fold 내부에서 수행한다. 01번 모델의 타깃은 로그 변환하지 않은 원래 사이클 단위의 `cycle_life`다.

### 모델 선택 및 근거

- 후보 모델 : 원래 수명을 예측하는 Ridge, 로그 수명을 예측하는 Ridge·ElasticNet. 피처·모델 비교는 02·03·04번 분석 노트북에서 수행한다.
- 최종 모델 : 본 보고서의 01번 기준 모델인 **Ridge 회귀(`alpha=0.01`)**.
- 선택 이유 : 두 피처와 수명의 관계를 선형식으로 설명할 수 있고, 계수 규제로 모델 복잡도를 조절할 수 있어 기준 모델로 선정했다. `alpha` 후보 `0.01, 0.1, 1, 10, 100` 중 Batch 1 개발 데이터의 3-fold 그룹 CV에서 MAPE가 가장 작은 값을 선택했다.

Batch 1을 개발 36셀과 hold-out 10셀로 나누고, 충전 정책 조합을 그룹으로 두어 같은 정책이 양쪽에 들어가지 않게 했다. Train 성능은 개발 36셀의 바깥 5-fold·안쪽 3-fold nested CV로 계산한다. Validation은 개발 데이터로 학습한 모델을 hold-out에 평가하고, Test는 설정 고정 후 Batch 1 전체 46셀로 재학습하여 Batch 2의 39셀에서 평가한다. 분할 시드는 `20261002`로 고정되어 있다.

추가 분석에서는 같은 셀과 분할을 사용해 다음을 비교했다.

- [02번: 한 피처 vs 두 피처](Modeling/02_Ridge_1vs2Features_Validation.ipynb) : ΔQ 로그 분산만 사용하는 Ridge와 SOC를 추가한 Ridge를 비교해, 두 번째 피처의 효과를 확인했다.
- [03번: 피처·모델 9조합](Modeling/03_Feature_Model_Validation.ipynb) : 피처 3종(ΔQ 로그 분산 / ΔQ 로그 분산+SOC / ΔQ 최솟값+SOC)에 원수명 Ridge·로그 수명 Ridge·로그 수명 ElasticNet을 각각 적용했다. Batch 1 개발 데이터의 CV로 조합과 설정을 선택했다.
- [04번: 로그 수명 Ridge](Modeling/04_Ridge_LogLife_2Features.ipynb) : 기존 두 피처를 유지하고 타깃을 `log10(cycle_life)`로 바꿨다. 03번은 자연로그를 사용하며, 로그 모델의 예측은 모두 사이클 단위로 역변환한 뒤 평가했다.

Batch 1에서는 비교적 작은 오차를 보였지만 Batch 2에서는 오차가 커졌습니다. Train은 학습 셀에 다시 예측한 오차가 아니라 nested CV 결과이며, 바깥 fold MAPE의 표준편차는 2.351%p입니다. Alpha 선택용 3-fold CV의 9.416%와 구분합니다. Validation은 10셀의 작은 표본이므로 낮은 오차만으로 과적합이 없다고 확정할 수 없다.

**추가 비교 결과** — 저장된 실행 결과 기준이며, 모든 점수는 MAPE(%)다.

| 실험 | 피처·모델 | Train (nested CV) | Valid | Test |
| --- | --- | ---: | ---: | ---: |
| 01번 기준 | ΔQ 로그 분산+SOC · 원수명 Ridge | 9.781 | 7.007 | 30.725 |

SOC 추가로 Test 오차는 0.812%p 낮아졌지만, 02번의 설정 선택용 CV에서는 한 피처가 선택됐다. 같은 두 피처의 로그 수명 Ridge는 원수명 Ridge보다 Test 오차가 3.760%p 커져, 로그 변환만으로 배치 차이가 해결되지는 않았다.

03번은 설정 선택용 CV에서 ΔQ 최솟값+SOC의 ElasticNet(`alpha=0.01`, `l1_ratio=0.9`)을 선택했으며, Valid/Test 점수는 선택에 사용하지 않았다. Test 오차는 기준 모델보다 3.792%p 낮았지만, 전체 9조합 선택 절차의 nested CV는 10.341%로 기준 모델보다 개선되지 않았다. 이 값은 선택된 조합만 고정한 nested CV 7.990%와 구분한다. 01번은 본 보고서의 기준 모델로 유지하며, 추가 후보의 개선 효과는 새 평가 데이터에서 검증해야 한다.



## 오류 분석

- 모델이 가장 크게 틀린 셀의 공통점
    - 가장 큰 오류는 B2_6(실제 393 → 예측 700.4사이클, 오차 78.23%), B2_15(396 → 694.3, 75.33%), B2_18(449 → 749.6, 66.95%)에서 나타났다. 짧은 수명의 셀을 더 오래 살 것으로 예측한 경우다.
    - 전체 39셀 중 35셀에서 수명을 과대예측했고, 평균 `예측 − 실제`는 +134.4사이클이었다. B2_6·B2_15의 SOC 9%는 Batch 1의 15–80% 범위 밖이지만, B2_18은 SOC 50%에서도 오차가 커 SOC 범위 차이만으로 설명할 수 없다. 상세 결과는 01번 실행 후 생성되는 `Modeling/results/ridge_step_by_step/`의 `test_predictions.csv`, `worst_test_errors.csv`에서 확인할 수 있다.

- 원인 가설 및 개선 방향
    - 라벨·코호트 정제 차이 : 공식 병합·수명 보정이 미적용이며 일부 Batch 1 셀은 높은 용량에서 기록이 끝난다. 공통 EOL 기준, 후속 기록, 관측 중단 여부를 먼저 확인한다.
    - 배치별 피처–수명 관계 차이 : ΔQ 로그 분산의 상관관계는 유지되지만 Batch 2에서 과대예측이 많다. 정책과 실험 조건별 회귀 관계·잔차를 비교해 같은 피처에서도 수명 관계가 달라지는지 확인한다.
    - 충전 조건 정보 부족 : SOC 하나로 C1·C2와 전체 프로토콜을 구분하기 어렵다. C1, C2, 초기 충전시간 등을 정제한 뒤 Batch 1 내부 CV에서 후보를 비교한다.
    - 짧은 수명에서 MAPE 증가 : 같은 사이클 오차도 실제 수명이 작으면 상대오차가 커진다. MAE·RMSE 및 수명 구간별 오차를 함께 확인한다.
    - 개선 순서 : 라벨·코호트 검증 → Batch 1 내부에서 피처·모델 선택 → 새 평가 데이터에서 검증. Hold-out과 Batch 2 점수는 설정 선택에 사용하지 않았지만 두 데이터 모두 이전 EDA에서 확인했으므로, 개선 효과를 확증할 새 평가 데이터가 필요하다.

## ESS 도메인 해석

초기 수명 예측 결과를 ESS의 점검과 유지보수 계획에 활용하려면, 예측 오차와 운전 조건 차이를 함께 고려해야 한다.

- 이 모델을 실제 BESS에 적용한다면 어떤 의사결정에 활용 가능한가?
    - 초기 운전 데이터로 수명 위험을 추정해 추가 점검할 셀·모듈의 우선순위와 유지보수 계획을 정하는 데 활용할 수 있다. 충전 정책과 수명 관계가 현장에서 검증되면 충전시간과 수명 사이의 운영 조건을 비교하는 근거로 확장할 수 있다. 현재 모델에서 운영 효과까지 검증한 것은 아니다.

- 어떤 한계가 있으며, 실 배포를 위해 추가로 필요한 것은 무엇인가?
    - 현재는 실험실 셀의 사이클 수명을 예측하며 Test MAPE가 30.725%이고 과대예측 경향이 있다. BESS의 교체 날짜나 팩 수명을 직접 결정하기에는 검증이 부족하다.
    - 현장 전류·전압·온도·SOC·방전 깊이·휴지시간과 장기 용량 측정이 필요하다. 사이클 열화와 달력 열화, 셀 간 편차와 팩 수준의 운전 조건도 반영해야 한다. 
    - 일관된 EOL·관측 중단 기준, 다른 사이트·기간·조건을 보류한 검증, 단순 기준 예측과의 비교, 예측 불확실성과 조건 변화에 따른 오차 모니터링이 필요하다.
